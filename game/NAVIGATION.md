# Adding Game Link to Main Website Navigation

If you want to add a link to the game in your main website navigation, you can add it to your `index.html` or any page.

## Option 1: Add to Main Navigation

In `waterlooTBOG/index.html`, find the navigation section and add:

```html
<a href="game/index.html" class="nav-link">Game</a>
```

Or add it as a dropdown item if you prefer.

## Option 2: Add to Footer

In the footer section, you can add:

```html
<a href="game/index.html">Beer Pong Heardle Game</a>
```

## Option 3: Standalone Link

Users can also access the game directly at:
```
https://yourdomain.com/game/
```
or
```
https://yourusername.github.io/waterlooTBOG/game/
```

---

**Note**: Make sure you've built and deployed the game files to the `game/` directory first!
